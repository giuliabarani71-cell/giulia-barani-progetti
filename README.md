# Giulia Barani · Progetti e performance

App HTML per gestire progetti fotografici, riprese, Reel, consegne e KPI di produttività e affidabilità.

## Uso
Aprire `index.html` nel browser. Non richiede installazione o server.

I dati inseriti sono salvati nel browser del dispositivo, non in GitHub. Usare **Salva backup** e **Importa backup** per trasferirli. Passando dal file locale a un indirizzo web occorre importare il backup, perché lo spazio di archiviazione cambia.

## Funzioni
- Più progetti con committenti, compensi e obiettivi contrattuali distinti.
- Riprese, conteggi foto e ripartizione automatica del tempo tra Reel.
- Tempi di selezione, editing, montaggio e altre attività.
- Consegne fotografiche e Reel con scadenze.
- KPI di produttività e affidabilità, storico ed esportazione CSV.

Il file include il logo Giulia Barani. Nessun backup di dati operativi è incluso nella repository.
